# ComptaSnap — Design

Maquettes mobiles (390×844) de l'app de suivi des dépenses, factures et reçus.

## Écrans
1. `01-bienvenue.html` — Bienvenue (non connecté)
2. `02-connexion.html` — Connexion
3. `03-tableau-de-bord.html` — Tableau de bord
4. `04-scanner-recu.html` — Scanner un reçu
5. `05-factures.html` — Factures
6. `06-logo.html` — Logo (+ `logo.svg`)

Ouvrir `index.html` pour voir tous les écrans côte à côte.

## Charte
- Fond sombre `#0E0F0C`, papier `#EDE8DC`, accent lime `#C6F432`, gris `#A9A595`, ligne `#2A2B25`
- Succès `#1E7A4F`, retard `#C73A10`, texte secondaire papier `#5E5A4E`
- Polices : **Bricolage Grotesque** (500/800) pour les titres et le texte, **JetBrains Mono** (400/700) pour les libellés, montants et navigation (Google Fonts)
- Esthétique « ticket de caisse » : bord dentelé, lignes pointillées, tampon incliné (`.st`)
